# 🎲 Dice Roller

A simple and interactive Dice Roller web application built with **HTML, CSS, and JavaScript**. Users can select the number of dice to roll, generate random dice values, and view corresponding dice images with smooth animations.

## ✨ Features

* Roll one or multiple dice at once
* Generates random values from 1 to 6
* Displays rolled numbers instantly
* Shows matching dice face images
* Responsive design for desktop and mobile
* Smooth dice roll animations
* Elegant casino-inspired user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🚀 How It Works

1. Enter the number of dice to roll.
2. Click the "Roll Dice" button.
3. JavaScript generates random numbers between 1 and 6.
4. The results are displayed as text and images.
5. Dice images animate into view for a better user experience.
